# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities, credentials, private
information, or exploitation details in a public GitHub issue.

Use the contact route on the BFEP website:

https://butterfly.joshcross.co.nz/contact-us

Include only the information needed to understand and reproduce the concern.
Do not include unrelated personal information or live credentials.

## Supported version

Security fixes apply to the version currently deployed on the public BFEP
website and to the latest source on the `main` branch.
